## The word

**vanisneeze** (vanish + sneeze): the sneeze that builds to the brink and then
fades away un-sneezed. Everyone has felt it — the tickle swelling, the breath
drawn in, the whole body braced — and then nothing. English has no word for
that almost-sneeze, so this one names it.
